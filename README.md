# log-analyzer

Консольный анализатор access-логов (формат combined, nginx и Apache) на Python. Без внешних зависимостей.

## Что показывает
- общее число запросов;
- долю ошибок 4xx и 5xx;
- самые популярные страницы (без query-строки);
- самые активные IP.

## Запуск
```
python log_analyzer.py access.log --top 10
```
Битые строки пропускаются, файл читается построчно, поэтому большие логи не забивают память.

## Тесты
```
python -m unittest -v
```

Учебный проект для портфолио. Python 3.9+.
